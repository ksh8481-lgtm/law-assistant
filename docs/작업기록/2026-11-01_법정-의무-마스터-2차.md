# 2026-11-01 법정 의무 마스터 2차 (별표·누락·채팅 근거)

[1차](2026-11-01_법정-의무-마스터-문제-해결.md)에서 남긴 "별표·시행령·고시를 안 본다"를 이어서 했다.

## 먼저 찾은 문제: 같은 입력인데 결과가 크게 흔들림
건설기술 진흥법 시행령의 같은 파트(제41~42조)를 여러 번 돌리면 의무가 9건 나오기도, 2건만 나오기도 했다(제42조 통째로 누락).
- 기본 프롬프트 4회: 제42조 의무 4, 0, 1, 0건 / 문구만 바꾼 여러 변형: 0~11건으로 들쭉날쭉.
- **원인**: 프롬프트가 의무 대상을 "행정/건설 관리기관, 사업주, 지자체 등"으로 좁혀 놓았는데, 제42조의 교육시간은 의무 주체가 **건설기술인**이라 모델이 어떤 때는 범위 밖이라 보고 `[]`을 돌려줬다. Pro 모델로 바꿔도 4회 중 2회가 0건이어서 생각을 더 시키는 것으로는 해결되지 않았다.
- **교정**: "이 법령이 지키도록 정한 의무 … 주체는 행정기관·발주청·지자체·사업주·사업자·건설기술인 등 법령이 의무를 지우는 모든 대상". 교정 후 같은 파트 10회 중 누락 0회(7~19건, 대부분 10~11건). 중대재해처벌법 전체는 교정 전과 같은 22건, 번호 22건 모두 확인.
- 부작용: 의무 주체가 넓어져 건설기술인·사업자 의무도 카드에 나온다(필터로 주체별 보기 가능). 의도한 변화다.

## 운영 배포 후 발견: 동시 요청 504
운영에서 파트 5개를 동시에 보내자 3개가 61초에 `504 Gateway Time-out`(HTML)으로 끊겼다. 하나씩 보내면 23~30초로 정상이었다.
- **원인**: 서버가 워커 1개 동기 방식이라 요청을 한 번에 하나씩만 처리한다. 뒤의 요청은 줄 서서 기다리다 게이트웨이 제한(60초)에 걸린다. 2차에서 파트 하나가 20~60초로 길어지면서(별표 첨부·재검토) 드러났다. 1차 확인 때는 가장 느린 파트가 58초라 간신히 통과했었다.
- **고침**: `gunicorn.conf.py` 추가(워커 1·스레드 8·gthread·제한 120초; gunicorn 21.2.0이 `./gunicorn.conf.py`를 자동으로 읽는 것을 소스에서 확인). 화면은 동시 요청을 5→3으로 줄이고, 504·연결 끊김이면 4초 뒤 1회 자동 재시도(로컬에서 504를 일부러 내 복구와 실패 표시 확인).
- 로컬은 Windows라 gunicorn을 못 돌려서 설정 적용은 배포 후 운영에서 5개 동시 요청으로 확인한다.

## 남은 것·한계
- `moleg_mcp._law_detail_text(include_byeolpyo=True)`는 새로 만들었지만 **첫 질의응답 경로는 기본 꺼짐**이다(프롬프트 크기·시간 변화 방지). 켜면 시행령·시행규칙 별표 수치를 첫 답변에도 쓸 수 있다 — 별도 검증 후 결정.
- 시행령·시행규칙의 의무를 법률과 한 화면에 합쳐 보여 주지는 않는다(각각 따로 선택).
- 재검토는 1회뿐이다. 모델이 그래도 비우면 그 조는 빠진다(위 교정 후 10회 중 0회).
- 채팅은 인용 주제 판정(`annotate_unverified_citations`)을 쓰지 않는다(30초 제한 때문). 선택한 법령은 원문이 그대로 들어가고 시행령·고시는 원문 발췌가 붙는다.
- 파트 하나가 20~60초 걸릴 수 있다(별표가 붙은 파트와 재검토 때). 큰 법령 전체는 여전히 오래 걸린다.

# 2026-11-22 Gemini 모델 교체 (2.5 폐기 대비)

## 문제
구글이 `gemini-2.5-pro`·`gemini-2.5-flash`를 폐기했고 **2026-12-01부터 모든 요청이 `gemini-3.8-flash` / `gemini-3.5-flash-lite`로 자동 연결**된다(요금도 새 모델 기준). 공식 이전 안내는 `thinking_budget` -> `thinking_level`,
`temperature` 등 샘플링 설정 제거를 요구한다. 이 앱은 `temperature`·`thinking_budget`을 여러 호출에서 쓴다. 가만두면 12/1 이후 오류·품질·비용 변화가 예측 불가였다.

## 호환 측정 (2026-11-22, 크레딧 충전 후 실제 API, 짧은 질문)
| 모델 | temperature | thinking_budget=512 | thinking_budget=0 | json_mode | 구글검색 |
|---|---|---|---|---|---|
| 2.5-flash | OK | OK | OK | OK | OK |
| 3.8-flash | OK | OK(사고 안 보임) | OK | OK | OK |
| 3.5-flash-lite | OK | OK | **400** | OK | OK |
- thinking_level: 3.8-flash 는 minimal **400**, low 는 사고 없음 3.0초, 기본(medium) 사고 ~750토큰 9~10초, high 13초. 3.5-flash-lite 는 모든 단계 허용, 기본은 사고 없음 1.3초, medium ~600토큰 3초.

## 모델 조합 비교 (같은 질문: 관광단지 면적 변경 + 재해영향평가, 기타 행정 검토 전체 파이프라인, 1회씩)
| 조합(본 답변 / 가벼운 호출) | 시간 | 입력 | 출력 | 생각 | 추정 비용 |
|---|---|---|---|---|---|
| 2.5-pro / 2.5-flash (기존) | 90초 | 57,071 | 3,271 | 12,089 | $0.14 |
| 3.8-flash / 3.8-flash | 77초 | 54,783 | 3,863 | 4,036 | $0.071 |
| 3.8-flash / 3.5-flash-lite | 80초 | 56,207 | 3,818 | 1,999 | $0.055 |
| 4-hydrogen / 3.8-flash | 97초 | 55,361 | 5,022 | 11,219 | $0.189 |
| 4-argon / 3.8-flash | 83초 | 53,463 | 7,761 | 1,106 | $0.172(답변 1.7만 자로 장황, 12월부터 단가 2배) |
- 다섯 조합 모두 시행령 제6조의2 수치·해석례 25-0166·시행령 제44조를 인용했고 "직접 확인하라"로 물러난 경우는 없었다(지표 기준, 3.8-flash 답변만 직접 읽어 확인).
- 호출별 실측: 본 답변 입력이 **약 47,000토큰**(법령 컨텍스트 + 지시문 + 로컬 DB). 처음 추정(31,000)보다 컸다. 기존 2.5-flash 의 가벼운 호출은 생각 토큰만 1~4천씩 써 합계 약 9천.
- 법령 선정(4개 질문 x 2회): 3.8-flash 가 가장 정확(건설사업관리·착공 질문에서 필요한 법령을 모두 선정), 3.5-flash-lite 는 법령명 띄어쓰기("건설기술진흥법" vs 공식 "건설기술 진흥법")만 다르고 실질 적중은 비슷, 2.5-flash 는 건설사업관리에서 건설산업기본법을 놓쳤다.

## 선택
- 본 답변·가벼운 호출 = `gemini-3.8-flash`. 도면 지번 추출(비전)·서류 정리 같은 가벼운 호출도 정확도가 필요해 lite 가 아니라 3.8-flash 를 쓴다.
- 추출 3종(입력 200~900토큰)만 `gemini-3.5-flash-lite`(사고 medium): 호출당 1.8~3.7초(전엔 7~13초). 사고를 medium 으로 둔 것은 "법령명 추출은 사고를 켜 둬야 법령이 안 빠진다"는 기존 측정을 따른 것.
- 인용 판정은 3.8-flash(기본 fast)에 둔다: 안전장치라 lite 로 내리지 않았다.
- 새 기본으로 다른 질문 3개 확인: 영업손실보상 79초 $0.06, 건설사업관리 60초 $0.064, 재난관리기금 69초 $0.055. 인용 점검은 정상 작동(건설사업관리에서 따옴표 문구 불일치 ⚠ 1건 포착). 후속 질문 채팅은 7.6~15초(생성 5초, thinking_level low).

## 코드 변경
- `gemini_client`: 기본 모델·`light_model()`, `model_generation`, `thinking_config_for`(예산 -> 단계), `generate`의 400 재시도(사고·temperature 제거), 같은 모델 중복 제거 + 마지막 예비 `gemini-3.6-flash`.
- `mcp_agent_sync`: 추출 3종 light 모델 + 사고 medium. `app.py`: 인용 검증 기본 모델을 main_model 로.
- 시험: `test_gemini_models.py` 신규(11개), `test_admrul.py`·`test_gemini_endpoints.py`를 새 기본값에 맞춤(엔드포인트 시험은 본/가벼운 모델이 다른 구성을 환경변수로 고정).

## 기각 / 보류
- 4-hydrogen·4-argon 을 본 답변에 쓰기: 이 질문에서 비용이 2~3배인데 품질 차이를 지표로 확인하지 못했다(argon 은 12/1부터 단가 2배).
- 다른 회사 API(Claude·GPT·Grok): 가격은 비슷한 구간이고 PDF 토큰 방식이 달라(구글은 쪽당 고정 258토큰) 이 앱에는 구글이 유리. 품질 비교는 별도 시험이 필요해 보류.
- `rag_app.py`(별도 Streamlit 실험 앱)의 `gemini-2.5-flash` 고정은 이번에 건드리지 않았다(운영 경로 아님).

## 한계 / 주의
- 질문 1건 기준 측정이라 통계적 결론이 아니다. 3.8 Flash 는 **2027-01-01부터 단가가 2배**($1.50/$7.50)가 되어 비용이 기존 수준($0.14 안팎)으로 돌아온다.
- 3.5-flash-lite 가격은 공식 페이지에서 확인하지 못해 근사값이다.
- Cloudtype 환경변수에 옛 모델명이 설정돼 있으면 그 값이 우선한다(운영안내 §15).
- 되돌리기: 환경변수 `GEMINI_MAIN_MODEL`/`GEMINI_FAST_MODEL`/`GEMINI_LIGHT_MODEL`로 모델 지정(코드 수정 불필요), 코드 되돌리기는 이 커밋 revert.

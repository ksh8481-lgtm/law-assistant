# 외부 API 연동 추천과 상담 내용 (2026-11-15, 클라우드 세션)

## 1. RTK·드론 측량 (사용자 질문: 토목AX 영상의 "RTK와 드론으로 측량")
- RTK: 기준국 보정 신호로 GPS 위치를 cm급(약 1~3cm)으로 잡는 측량. 기준점·높이·측설에 사용.
- 드론: 겹쳐 찍은 사진으로 정사영상·지형(DEM)·3D 점군 생성. 넓은 구간을 빠르게. 지상기준점(GCP)을 RTK로 측량해 좌표 정확도를 맞춤.
- 공사 카드 연결 구상: 실제 지형 위 3D 모형, 토공량 계산, RTK 좌표로 편입 필지 지도와 겹치기, 공사 전후 드론 영상으로 준공 이력.
  → 파일 형식(GeoTIFF, LAS 등)을 사용자에게 확인한 뒤 판단.

## 3. 발견한 보안 문제 (사용자 결정 대기)
- `.env_example`에 브이월드 API 키가 실제 값으로 커밋되어 있음. 저장소가 공개라면 누구나 사용 가능.
- 권장: 브이월드에서 재발급 → Cloudtype 환경변수 교체 → 예시 파일을 `"여기에_브이월드_키_입력"`으로 변경. 재발급은 사용자가 직접.

# 2026-11-01 법정 의무 마스터 문제 해결

## 배경
`/duty_list`(법정 의무 마스터)는 법령 본문을 1,500자씩 기계적으로 잘라 파트마다 Gemini flash에게 의무사항을 JSON으로 뽑게 하고,
화면이 5파트씩 동시에 요청해 주체별 카드로 보여 준다. 코드를 읽어 아래 문제를 찾았다(2026-11-01).

## 고친 것
| 문제 | 고친 방법 |
|---|---|
| 항 내용 전부 → 호 내용 전부 순서로 이어 붙여 호가 엉뚱한 항 뒤에 붙고, 목 내용은 아예 빠짐 | 조문 → 항 → 호 → 목을 문서 순서대로 읽음(`duty_text.article_text`). 실제 법령(건설기술 진흥법 제2조 제2호의 목)으로 시험 |
| 항·호 텍스트가 비면 조각 하나가 통째로 오류 | 비어 있는 항목은 건너뜀 |
| 글자 수로 자르면 조문 중간에서 끊겨 조 번호를 잃음 | 조문 경계에서만 자름. 긴 조문은 줄 단위로 나누고 `〔제N조 계속〕` 표시. 모델에게 이 파트의 조 목록도 알려 줌 |
| 모델이 쓴 조 번호가 맞는지 확인 안 함(법제처 링크로도 쓰임) | 파트에 실제로 있는 조인지 서버가 대조 → `article_verified`. 틀리면 화면에서 링크 대신 ⚠️ 표시 |
| 같은 조·같은 제목 카드가 중복 | 서버와 화면에서 걸러냄 |
| JSON이 깨지면 조용히 "의무 없음"으로 처리 | JSON 모드 사용, 깨지면 1회 재시도, 끝내 실패하면 `parse_failed`로 알림 |
| 일부 파트가 실패해도 "모든 조항 분석 완료"라고 표시 | 실패 파트 수 경고 + "실패한 파트 다시 분석" 버튼 |
| 시행일을 보여 주지 않음 | 법제처 기본정보의 시행일자를 완료 문구에 표시 |
| 채팅이 큰 법령은 앞 3만 자만 봄 | 질문 낱말이 많이 나온 조문부터 3만 자까지 골라 담음(발췌 안내 포함) |
| 모델 출력을 화면에 그대로 넣음 | `esc()`로 이스케이프 |
| 안 쓰는 옛 `/api/search_duties`(의무 7개 제한) | 삭제 |
| 법령 본문 캐시가 무제한 | 최근 16개만(`duty_text`) |

## 확인
- 새 시험 `test_duty_text.py` 20개 통과(법제처 실제 법령 1건 포함). 기존 `test_gemini_endpoints.py` 12개, `test_admrul.py` 49개 통과.
- 로컬에서 실제 Gemini로 건설기술 진흥법 파트 3개 시험: 조 번호 3/3 확인됨.
- 로컬 브라우저에서 중대재해 처벌 등에 관한 법률 분석: 5파트 33초, 카드 21개 전부 번호 확인됨, 시행일 표시. 실패 파트를 일부러 만들어 경고와 재시도 버튼 동작 확인. 채팅 답변(제4조, 제9조 인용) 확인.

## 남은 것 (다음 단계)
- 별표·부칙·시행령·시행규칙·고시는 아직 보지 않는다(본문 조문만). 의무의 기한·주기가 시행령 별표에 있으면 비어 보일 수 있다.
- 채팅에 고시·시행령 원문 근거를 붙이는 작업(후속 질의에 한 것과 같은 방식).
- 조 번호 대조는 "그 파트에 있는 조인가"까지만 본다. 인접 조를 잘못 적은 경우는 못 잡는다.
- 파트가 40개 안팎인 큰 법령은 여전히 오래 걸린다(서버 worker 1개).

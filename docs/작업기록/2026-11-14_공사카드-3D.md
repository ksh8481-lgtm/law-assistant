# 공사 카드 3D 시각화 (2026-11-14)

## 배경
다른 지방 토목직의 '토목AX' 구상(민원 → 측량 → 설계 → 3D 모형 → 서류 → 계약·착공 → 준공을 '공사 카드' 하나로 연결)을 참고해,
법규 검토 입력(체크리스트)에 "설계 수치 입력 → 3D 모형 + 수량 자동 산출"을 붙였다. 원본은 Claude 앱에서 만든 독립 페이지 `tomok-3d.html`.

## 한 일 (인계 메모의 할 일 1~5)
1. **3D 보기 화면**: `/tomok_3d`(`templates/tomok_3d.html`), 홈 카드 추가. 법규 검토 화면의 [📐 설계 수치] 칸에서 [🧊 3D 보기]를 누르면 같은 화면 아래에 펼쳐진다(`?embed=1`, iframe).
2. **값 연결**: `static/tomok_card.js`가 사업명·설계 수치를 바꿀 때마다 `postMessage({type:'tomok-card', card})`로 넘긴다(같은 서버 화면에서 온 메시지만 받음). [새 창으로 열기]는 `/tomok_3d#card=<JSON>`.
   `window.loadCard()`도 그대로 있다.
3. **입력 칸**: 연장 L·포장 폭 B·두께 T·줄눈 간격·수로관 규격·1본 길이·집수정 간격. 작성 중 보관·저장된 분석(`requestData.design`)에 함께 남는다.
   [📝 사업 내용에 넣기]는 수치와 수량을 한 줄(`- [설계 수치] ...`)로 [주요 사업 내용]에 넣는다(다시 누르면 그 줄을 바꿈). 서버 분석 로직은 바뀌지 않았다.
4. **오프라인**: three.js 0.160.0(`three.module.min.js`, `OrbitControls.js`, MIT LICENSE)을 `static/vendor/three/`에 넣고 importmap으로 연결. 3D 화면은 외부 요청이 없다.
   WebGL을 못 쓰는 PC에서는 안내문을 띄우고 수량표는 그대로 보인다.
5. **표준도 치수**: KS·제품 규격표에서 300C~600C의 벽 두께를 확인하지 못해 **수치를 지어내지 않았다.** 대신 단면 치수(내폭·내고·측벽·바닥 두께, 집수정 외폭·깊이)를
   3D 화면에서 규격별로 입력하고 [표준도 값으로 저장]하면 이 브라우저에서 그 규격의 기본값이 된다. 현재 상태를 "가정값 / 저장한 표준도 값 / 직접 입력"으로 표시.
   가정값: 내폭=내고=규격, 벽·바닥 = 규격×18%(최소 60mm), 집수정 외폭 = 수로 외폭+300, 수로 아래 깊이 300.
   → **할 일**: 사용하는 표준도의 값을 확인해 `assumedDims()`(templates/tomok_3d.html)의 표로 바꾸면 모든 사용자의 기본값이 된다.

## 원본 대비 고친 점
- 두께가 수로관 외고보다 크면 노반 높이가 음수가 되던 것(0 이상으로 제한), 줄눈·이음매 수 상한(2,000개).
- CSV 칸을 따옴표로 감싸고 파일 이름에서 쓸 수 없는 글자 치환, 수량표에 수로관 콘크리트 체적(참고) 추가.

# 2026-11-01 법정 의무 마스터 '내 문서' 기능

## 요청
의무 카드의 네모 체크칸은 "선택해서 프린트"에만 쓰였다. 체크하면 **그 항목이 문서에 바로 기록**되고, 체크한 것이 쌓여 **한 장의 문서**가 되며,
그 문서를 프린트할지 다른 방식으로 낼지는 **옵션**으로 고르게 해 달라.

## 동작
- 카드 오른쪽 위 **'문서에 담기'** 체크칸 → 누르는 즉시 문서에 추가, 풀면 문서에서 빠짐.
- 화면 왼쪽 아래 **📄 내 문서 (건수)** 버튼 → 한 장짜리 문서 창이 열린다. 법령별 → 의무 주체별로 묶고 조 번호 순으로 정렬, 표(☐ 조문 / 의무 / 점검 주기).
  문서 제목은 직접 고칠 수 있고, 항목마다 ✕로 뺄 수 있다.
- **출력 옵션**: 🖨️ 인쇄(문서만 나오게 인쇄, PDF 저장도 이 창에서) · 📋 텍스트 복사 · 📊 엑셀(CSV, 한글 깨짐 방지 BOM) · 📝 워드(.doc) · 🗑 모두 비우기.
- 법령을 바꿔 검색해도 문서는 유지되어 **여러 법령의 항목이 한 문서에** 모인다. 새로고침해도 이 브라우저(localStorage)에 남는다.
- **☑ 보이는 항목 모두 문서에 담기**: 주체 필터를 적용한 채 화면에 보이는 항목을 한꺼번에 담는다(카드를 하나씩 체크하기 번거로울 때).
- 조 번호가 원문과 맞지 않은 항목(⚠️)은 문서에도 ⚠️로 표시하고, 문서 맨 아래에 "AI 요약이므로 원문 확인" 안내를 넣는다.

## 같이 고친 것
- 예전 체크는 카드 요소 안에만 있었고 카드를 추가할 때마다 목록 HTML을 다시 만들어(`innerHTML +=`) **분석 도중에 체크하면 풀렸다**. 이제 체크 상태는 문서 데이터가 기억하고 카드는 `insertAdjacentHTML`로 덧붙인다(분석 도중 체크해도 유지됨을 확인).
- 기존 '선택 프린트' 코드·스타일·헤더의 프린트 버튼 제거(문서 인쇄로 대체).

## 확인
- 로컬 브라우저에서 중대재해처벌법·시행령으로: 체크→문서 반영, 분석 도중 체크 유지, 주체 필터+전체 담기, 두 법령 합쳐지는 문서, 항목 빼면 카드 체크 해제, 제목 저장, ESC 닫기, 새로고침 후 유지, CSV·텍스트·워드 생성 결과 검사(워드 파일에 ✕ 버튼 없음), 인쇄 규칙 적용 시 문서만 남는지(계산된 스타일로 확인).
- `test_duty_text.py`에 페이지 구성 시험 추가.

## 한계
- 실제 프린터 미리보기 화면은 자동으로 확인하지 못했다(인쇄 규칙을 적용했을 때 사이드바·본문·채팅·버튼이 숨고 문서만 남는 것은 확인). 처음 쓰실 때 인쇄 미리보기에서 한 번 봐 주세요.
- 저장은 브라우저별이다. 다른 PC·브라우저에는 따로 쌓인다. 개인정보 보호 모드나 저장소를 막은 환경에서는 그 방문 동안만 유지된다.
- 같은 법령을 다시 분석하면 AI가 제목을 조금 다르게 쓸 수 있어, 이전에 담은 항목이 새 목록에서 "체크된 상태"로 표시되지 않을 수 있다(문서에는 그대로 남는다).

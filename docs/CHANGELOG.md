## 항목 추가 요령

- 한 줄로 쓴다: **무엇이 바뀌었나**(사용자 입장) + 필요하면 괄호로 이유.
- 커밋 번호는 **푸시한 뒤** 확정된 번호를 쓴다(`git pull --rebase`로 번호가 바뀔 수 있다).
- 문서(`docs/`, `CLAUDE.md`)만 바꾼 변경은 이 표에 적지 않는다(끝없이 자기 자신을 기록하게 되므로).
- 서버 동작이 바뀐 변경은 배포 후 `docs/운영안내.md`의 확인 절차를 돌리고 ✅로 바꾼다.
